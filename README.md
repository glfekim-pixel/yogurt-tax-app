# 요거트아이스크림의정석 매장관리 앱

매출·매입·세금을 한눈에 관리하는 모바일 전용 웹앱입니다.

## Vercel 무료 배포 방법 (5분 완성)

### 1단계 — GitHub에 코드 올리기

1. github.com 회원가입 (무료)
2. New repository → 이름: yogurt-tax-app → Create
3. 아래 명령어 실행:

```bash
git init
git add .
git commit -m "초기 배포"
git branch -M main
git remote add origin https://github.com/본인아이디/yogurt-tax-app.git
git push -u origin main
```

### 2단계 — Vercel 배포

1. vercel.com → GitHub로 로그인
2. Add New Project → yogurt-tax-app 선택
3. Deploy 클릭 → 1~2분 후 URL 생성

예: https://yogurt-tax-app.vercel.app

### 3단계 — 카카오톡 공유

앱 내 [카카오 공유] 버튼을 누르면 링크가 복사됩니다.
카카오톡에 붙여넣기 후 전송하세요.

## 모바일 홈 화면에 추가

**아이폰**: Safari → 공유 → 홈 화면에 추가
**안드로이드**: Chrome → 메뉴(⋮) → 홈 화면에 추가
